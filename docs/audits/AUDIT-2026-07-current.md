# BerryBrain Current Audit

Date: 2026-07-13

## Environment Baseline

- Docker: 29.3.1
- Docker Compose: v5.1.1
- Node: v22.23.1
- Python: 3.12.13
- SQLite: 3.46.1

## Verified

- `docker compose config --services` includes `api`, `web`, and `worker`.
- `docker compose up -d` starts API, Web, and Worker.
- API container reports healthy.
- Worker container starts and sends heartbeat to the API.
- Web landing loads under `/berrybrain` without client-side exception.
- Prefixed Next assets under `/berrybrain/_next/*` load without 400 after middleware fix.
- API suite: 156 tests pass; the last measured disposable Python 3.12 coverage run reached 76% total coverage against the 60% gate.
- Worker suite: 34 tests pass, including disposable-DB integration tests.
- Web typecheck and production build pass; lint has no errors.
- Semantic and insight usefulness benchmarks are reproducible.
- Graph writes are canonicalized and active AI edges require traceable evidence or become stale.
- Backup/restore validates SHA-256, reports restored items, migrates compatible schemas, and rejects corruption.
- Tesseract is present in the rebuilt API image and extracted text from a repository screenshot.
- Cloud content requires explicit consent; prompt injection policy and secret redaction have automated tests.
- Clean disposable-stack baseline on 2026-07-13: all services healthy in approximately 65 seconds, note creation in 6 seconds, complete 14-stage pipeline in 163 seconds, and degraded semantic search in 2.02 seconds with Ollama unavailable.
- The clean baseline reached 100% pipeline completion without dead-letter jobs while provider-dependent stages used explicit deterministic fallbacks.
- Worker health now uses an unambiguous UTC heartbeat; the clean container remained healthy after processing.
- Note saves use optimistic concurrency with the content hash read by the editor. Stale saves return HTTP 409, preserve both the current vault file and local draft, and offer explicit reload or overwrite resolution.
- Login now honors the visible `remember_me` choice; automated tests distinguish session-only cookies from 30-day persistent cookies.
- Production-browser suite: 13/13 tests pass against an isolated authenticated stack. Coverage includes landing-to-login owner entry with no default password, `Ctrl+K` + `Enter` note creation, deterministic `Escape`, mobile workspace without horizontal overflow, and actionable Home degradation.
- Custom self-hosted Web origins are propagated through Compose, so CSRF-protected mutations continue to work when the Web port or public URL differs from the default.
- Trivy local release gate passes for API, Worker, and Web with zero fixable HIGH/CRITICAL findings. The Web runtime uses Next standalone output, excludes npm/build dependencies, runs as `node`, and is approximately 85 MB.
- Sandboxed Tesseract validation against the repository screenshot completed with 6,218 extracted characters, 258 located words, and 0.795 average confidence.
- MyPy, Ruff check/format, Web typecheck/lint/production build, `pip-audit`, and the high-severity npm audit gate pass locally.
- Local SPDX JSON SBOMs were regenerated from the final images with Syft for API (233 packages), Worker (110 packages), and Web (154 packages); release attestation remains pending until a signed tag workflow runs.
- Versioned Worker prompts are copied into the runtime image and missing/empty prompts fail explicitly; the previous invalid `apps/prompts` lookup can no longer degrade AI jobs into promptless calls.
- Worker responsibilities for API transport, resilience/circuit breaking, prompt loading, chunking, and deterministic fallbacks are split into dedicated tested modules.
- The API image bundles Faster Whisper and a commit-pinned `tiny.en` model. A real WAV was transcribed through the production sandbox on ARM64 with timestamps and confidence; the rebuilt image passes pip-audit and Trivy HIGH/CRITICAL gates.
