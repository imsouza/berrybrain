# Product Maturity

BerryBrain release maturity requires:

- Real vault data only in production paths.
- English system UI, prompts, messages, and generated output.
- Canonical graph ontology and validated relationship domains.
- Evidence-backed retrieval and generated insights.
- Calculated, read-only confidence with provenance.
- Idempotent maintenance and recovery operations.
- Passing unit, integration, build, and browser checks.
- Healthy production containers after rebuild.

Detailed checks are tracked in `v1-4-1-graph-ontology-confidence.md`.
