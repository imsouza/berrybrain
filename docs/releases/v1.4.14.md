# BerryBrain 1.4.14 — auditable evidence support

Product maintenance only; no new research/research experiments.

## Changes

- Fix repeated 50% values caused by taking the midpoint of broad 0–1 intervals.
  Report the mean of actual signals, with uncertainty kept separate.
- Persist signal scores and sources. Provenance-only identifiers do not count as
  measurements. Genuine zero is retained; missing evidence is not a zero verdict.
- Update evidence support after Judge evaluations. Internal judges must return
  five valid rubric scores; the backend derives the normalized mean and applies
  numeric verdict rules. The versioned prompt is `artifact-judge.v3.md`.
- Treat a committee aggregate as one observation; repeated evaluations replace
  the old Judge signal. Invalid scores/verdicts are rejected at the API boundary.
- Preserve original source evidence during semantic enrichment, avoiding a
  self-invalidating source fingerprint. Recalculation recovers saved semantic
  measurements only when the profile version and source fingerprint match.
- Show Evidence support, Not evaluated and Needs recalculation explicitly.
  Home excludes missing and legacy midpoint values from averages and handles
  1% correctly instead of displaying 100%.

## Compatibility and deployment

The API retains `confidence` field names and existing units. Full intervals add
`observations`, `interpretation` and `needsRecalculation`; absence of a measurement
is represented by a null score. Strict evaluation submission accepts numeric 0–1
scores and supported verdicts only. Clients must handle nullable fields.

No schema migration. The existing `confidence_factors` JSON column now stores a
versioned object; legacy arrays remain readable. Back up before deployment and
retain the previous images. Old binaries do not understand the new observation
object for future recalculation; restore the matching backup if rolling back
writes, rather than silently mixing old/new scoring semantics.

Historical midpoint values cannot be inverted into lost measurements. Scoped
recalculation preserves recoverable observations; otherwise a record remains
unavailable until legitimate evaluation. This release does not launch bulk paid
inference, change providers, erase failures or promise factual calibration.
