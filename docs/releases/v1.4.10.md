# BerryBrain v1.4.10

Product maintenance and reusable API release. Includes the changes prepared for
1.4.9 plus the source-map-js security correction. The existing 1.4.9 tag remains
unchanged; its image/release pipeline was cancelled before GitHub Release
publication. The frozen research artifact and thesis results are unchanged.

## Product and architecture

- [External REST API documentation](../api.md), OpenAPI/Swagger, discovery,
  independent expiring/revocable service tokens and a standalone Python client.
- Stable note identity, conflict detection, asynchronous jobs, paginated graph
  access and evidence-grounded Ask for applications beyond the web interface.
- Indexed Home/Monitor statistics, bounded history reads, correct failure counts,
  lease-aware worker health and safe note/folder organization.
- OpenCode Zen capability-aware setup, independent generation/embedding routes,
  Markdown-rendered Ask answers and improved graph interaction.
- Canonical folder containment, authentication/CSRF corrections, streamed request
  limits and compatibility-preserving token handling.

## Security and verification

The dependency set includes Next.js 15.5.27, Sharp 0.35.5 and source-map-js 1.2.2;
the API requires AnyIO >= 4.14.2. Production dependency audits, CodeQL, container
scans, backend/worker checks, browser smoke tests and isolated product checks are
required before merging the release preparation PR.

The preceding system checks recorded 709 checks across 86 isolated modules and
80.62% combined backend coverage. These are software checks, not new scientific
results. See the [publication checklist](../reviews/2026-10-07-release-1.4.10.md)
and the GitHub Actions runs for the exact revision being verified.

## Upgrade and remaining limits

Back up SQLite and the Markdown vault before upgrading. Schema remains 14;
upgrading from the local 1.4.9 deployment requires no new schema migration.
Existing tokens and user data are preserved.

API clients share one owner-managed workspace. Per-token scopes and per-vault
authorization remain future work; do not expose this as a multi-tenant service.
Development-toolchain advisories remain in braces and postcss-selector-parser
(seven high and two moderate audit entries on 2026-10-07); they are not in the
production dependency audit. Use trusted build/lint inputs and plan a compatible
toolchain migration instead of forcing a breaking dependency upgrade.

No bug-free, exclusively local inference or fixed-latency guarantee is made.
