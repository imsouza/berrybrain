# BerryBrain 1.4.11 — operation and workspace usability

This is a product maintenance release, not a new research evaluation.

Activity and Monitor use compact, paginated history. Exhausted jobs are visible
under Failed, global queue counts no longer represent only a recent sample,
and an unavailable optional diagnostic no longer blanks the entire panel.
Settings includes automation-log viewing and JSON export (up to 1000 entries).
Export excludes snapshots and redacts known secret patterns, but can still
contain private paths and descriptions: review before sharing.

Workspace navigation persists on Ask, Activity, notes and graph pages. Ask uses
suggestion cards and does not download the entire graph. Mermaid and LaTeX are
supported in note previews with restricted rendering. Insecure HTTP disables
voice input with an explanation; use trusted HTTPS for browser microphone access.

Graph ontology shapes and semantic colors are unchanged. Hover shows one
tooltip; dragging fixes a node while unpinned neighbors settle. Session-local
positions survive graph refreshes. Progressive reads show available nodes and
an explicit retry warning if later pages fail.

Observed provider model/capability failures generate notifications. These do
not certify provider-catalog removal, run paid probes, or replace models.
See [API contracts and limitations](../api.md) and the
[implementation checklist](../reviews/2026-10-08-system-usability.md).

Schema remains 14. Existing failed jobs, Markdown vaults, SQLite data and
credentials are preserved. Do not bulk-retry historical failures just to clear
a counter. Keep a verified private backup and the previous images for rollback.
