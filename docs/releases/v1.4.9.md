# BerryBrain v1.4.9

Product maintenance release. This version does not replace the frozen v1.4.8
research artifact or add new thesis experiments.

## Reusable architecture and API

- [External REST API guide](../api.md), versioned discovery, OpenAPI and Swagger.
- Independent expiring/revocable service tokens and a
  [standalone Python client](../../examples/berrybrain_client.py).
- Notes with stable identity and conflict detection, asynchronous jobs, paginated
  graph access and evidence-grounded Ask, without depending on the web frontend.
- Explicit authentication boundaries, streamed request limits, redacted errors
  and rejection of locked sessions or expired service tokens.
- AnyIO >= 4.14.2 addresses upstream security advisories. Folder operations check
  canonical path containment, including symlinks and platform-specific paths.

## Product fixes

- Indexed Home/Monitor statistics, bounded history reads, correct failure counts
  and lease-aware queue health.
- Note assimilation survives renaming without accepting stale content hashes;
  note organization preserves identity and attachment references.
- OpenCode Zen setup checks model capabilities. Generation and embeddings can
  use different providers; chat-only models are not advertised as embedding models.
- Grounded Ask study guides render Markdown. Graph nodes retain their ontology
  shapes with smaller sizes, contextual labels and interaction improvements.
- An explicit-ID administrative tool reconciles exhausted legacy pending jobs;
  dry-run is the default and applying records an audit event without model calls.

## Upgrade and limits

Back up the SQLite database and Markdown vault before upgrading. Schema migration
14 adds five indexes without deleting notes, jobs or historical evidence. Reverting
to an older API requires checking schema compatibility; changing only the image
is not a complete rollback procedure.

API consumers currently share one owner-managed workspace. Per-token scopes and
per-vault authorization are not implemented. Runtime latency remains dependent
on the host and workload; no bug-free or fixed-latency guarantee is made.

The [local verification record](../reviews/2026-10-03-release-1.4.9.md) includes
686 checks in the full isolated Python run plus 8 later reconciliation checks,
14 web unit tests and 2 API-documentation browser checks. These are software
checks, not new scientific results. Remote CI status must be checked separately.
